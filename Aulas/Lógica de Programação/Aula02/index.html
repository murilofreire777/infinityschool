O que é uma condição?

Condição é uma expressão que pode ser avaliada como True ou False, controlando o fluxo do programa.

x = 10
print(x > 5)   # True
print(x == 0)  # False
Exercício 1: Crie uma condição para verificar se um número é maior que 100.

Usando if, else e elif

nota = 7
if nota >= 6:
    print("Aprovado")
else:
    print("Reprovado")

idade = 18
if idade < 12:
    print("Criança")
elif idade < 18:
    print("Adolescente")
else:
    print("Adulto")
Exercício 2: Crie um programa que leia um número e diga se ele é positivo, negativo ou zero.

Operadores Lógicos

  • and — verdadeiro se ambas condições forem verdadeiras
  • or — verdadeiro se pelo menos uma condição for verdadeira
  • not — inverte o valor lógico
x = 10
y = 20
print(x > 5 and y > 5)   # True
print(x > 15 or y > 15)  # True
print(not(x > 5))        # False
