Aula 03 — Estrutura de Repetição while

Laços permitem repetir instruções até que uma condição deixe de ser verdadeira.

Objetivos

  • Entender quando e por que usar laços.
  • Compreender a estrutura e o fluxo do while.
  • Usar contadores e acumuladores com segurança.
  • Evitar loops infinitos e validar entradas.

Agenda

  1. Motivação e conceito de loop
  2. Estrutura do while
  3. Contadores e acumuladores
  4. break e continue
  5. Validação de entrada / sentinela
  6. Prática

Motivação: por que loops?

Repetição manual é propensa a erros. Loops automatizam tarefas repetitivas, economizando tempo e reduzindo falhas.

Contando de 1 a 5
i = 1
while i <= 5:
    print(i)
    i += 1  # contador evita loop infinito

Estrutura do while

Enquanto a condição for True, o bloco repete.

Esqueleto
while condição:
    # bloco repetido
    # atualização de variáveis (contador/acumulador)
Senha até acertar (simples)
senha_certa = "python123"
senha = input("Senha: ")
while senha != senha_certa:
    print("Senha incorreta. Tente novamente.")
    senha = input("Senha: ")
print("Acesso liberado!")
Exercício 1: Peça ao usuário um número entre 1 e 10. Enquanto o valor for inválido, repita o pedido.

Contadores e Acumuladores

contador soma 1 a cada ciclo; acumulador soma um valor variável.

Contador de pares até 20
i = 0
while i <= 20:
    print(i)
    i += 2  # contador em passos de 2
Somatório com sentinela (0 encerra)
total = 0
n = float(input("Número (0 para sair): "))
while n != 0:
    total += n  # acumulador
    n = float(input("Número (0 para sair): "))
print("Soma:", total)
Exercício 2: Leia vários preços e calcule o total e a média; pare quando o usuário digitar um valor negativo.

Controle de fluxo: break e continue

Interrompendo com break
i = 1
while True:
    if i > 5:
        break  # sai do laço
    print(i)
    i += 1
Pulando pares com continue
i = 0
while i < 10:
    i += 1
    if i % 2 == 0:
        continue  # pula o restante do ciclo
    print(i)  # imprime apenas ímpares

Validação de entrada e prevenção de loops infinitos

While com tentativas
tentativas = 3
while tentativas > 0:
    pin = input("PIN: ")
    if pin == "1234":
        print("OK")
        break
    tentativas -= 1
    print("Restam", tentativas, "tentativas")
else:
    print("Cartão bloqueado")  # executa se não houver break
Loop robusto com conversão segura
while True:
    txt = input("Digite um inteiro: ")
    if txt.isdigit():
        n = int(txt)
        print("Você digitou:", n)
        break
    print("Valor inválido.")

Exercícios Finais

  1. Peça números inteiros até que 0 seja digitado; exiba soma e quantidade.
  2. Tabuada: leia um número e mostre multiplicações de 1 a 10 usando while.
  3. Jogo de adivinhação: o usuário tenta acertar um número secreto de 1 a 50; informe "maior"/"menor" até acertar.
  4. Menu: 1) somar, 2) subtrair, 0) sair — repita até o usuário escolher sair.
  5. Validação: leia nota entre 0 e 10; continue pedindo até receber um valor válido, então mostre a nota.
