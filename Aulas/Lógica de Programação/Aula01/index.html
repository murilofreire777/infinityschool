O que é um Algoritmo?

Um algoritmo é uma sequência finita de passos que descreve como resolver um problema.

Exemplo cotidiano: Receita de suco de laranja.
  1. Pegar laranjas.
  2. Cortar ao meio.
  3. Espremer.
  4. Adicionar açúcar/água se necessário.
Exercício 1: Crie um algoritmo para preparar um sanduíche.

Noções de Lógica

Lógica de programação organiza o raciocínio para resolver problemas de forma estruturada.

Atenção: Um algoritmo deve ter início, meio e fim bem definidos.
Exercício 2: Descreva em passos a rotina de acordar e se arrumar para sair.

Variáveis e Tipos de Dados

  • int — números inteiros
  • float — números decimais
  • str — cadeias de caracteres
  • bool — valores lógicos
Exemplo
idade = 25          # int
altura = 1.75       # float
nome = "Maria"      # str
ativo = True        # bool

Operadores Aritméticos e Relacionais

  • +, -, *, /, //, %
  • ==, !=, >, <, >=, <=
x = 10
y = 3
print(x + y)   # 13
print(x > y)   # True

Visão Computacional de Dados Booleanos

No computador, True equivale a 1 e False a 0.

  • bool(0) → False
  • bool("abc") → True
