Estrutura do for

O for percorre cada item de uma sequência, atribuindo-o a uma variável de controle.

Contando de 1 a 5
for i in range(1, 6):
    print(i)
Tabuada de 7
n = 7
for i in range(1, 11):
    print(n, 'x', i, '=', n*i)
Exercício 1: Leia um número do usuário e imprima a tabuada de 1 a 10 usando for.

Função range(início, fim, passo)

  • range(fim) → 0 até fim-1
  • range(início, fim) → início até fim-1
  • range(início, fim, passo) → define salto
Pares até 20
for i in range(0, 21, 2):
    print(i)
Contagem regressiva
for i in range(5, 0, -1):
    print(i)
print("Vai!")
Exercício 2: Mostre apenas os múltiplos de 3 entre 1 e 30 usando range com passo.

Iterando sobre Strings e Listas

String → caracteres
texto = "Python"
for ch in texto:
    print(ch)
Lista → itens
nomes = ["Ana", "Bia", "Caio"]
for nome in nomes:
    print("Olá,", nome)
Com índice com enumerate()
frutas = ["maçã", "banana", "uva"]
for i, fruta in enumerate(frutas, start=1):
    print(i, fruta)
Iteração paralela com zip()
alunos = ["Lia", "Rui", "Tom"]
notas  = [8.5, 7.2, 9.1]
for aluno, nota in zip(alunos, notas):
    print(aluno, "→", nota)

Introdução a Listas

Lista é uma coleção ordenada e mutável de elementos.

  • Criação: nums = [10, 20, 30]
  • Acesso: nums[0], nums[-1]
  • Atualização: nums[1] = 99
  • Métodos: append(), insert(), remove(), pop(), sort()
  • Tamanho: len(nums)
Operações básicas
nums = []
for n in range(1, 6):
    nums.append(n)
print(nums)        # [1, 2, 3, 4, 5]
nums.pop()         # remove o último
nums.insert(0, 99) # insere no início
print(len(nums), nums)
