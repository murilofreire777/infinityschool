# Módulo — Lógica da Programação 2025

Este módulo contém as aulas introdutórias de **Lógica de Programação em Python**, organizadas em páginas HTML com suporte de CSS e JS reutilizáveis.

## Estrutura de Pastas
```
/ (raiz)
├── index.html       # Índice do módulo
├── styles.css       # Estilos reutilizáveis
├── script.js        # Funcionalidades JS reutilizáveis
├── Aula01/
│   └── aula01.html  # Aula 01 — Algoritmos, Lógica e Tipos de Dados
├── Aula02/
│   └── aula02.html  # Aula 02 — Estruturas Condicionais
├── Aula03/
│   └── aula03.html  # Aula 03 — Estrutura de Repetição While
└── Aula04/
    └── aula04.html  # Aula 04 — Estrutura de Repetição For e Listas
```

## Recursos Inclusos
- **Tema claro/escuro** com alternância manual e persistência em `localStorage`.
- **Controle de fonte** (A+, A−) para acessibilidade.
- **Sumário automático** (TOC) gerado a partir dos títulos da aula.
- **Barra de progresso de leitura** no topo.
- **Blocos de código** com botão de copiar.
- **Imagens com zoom** em modal.
- **Exercícios práticos** (2 durante e 5 no final de cada aula).
- **Quiz interativo** com correção instantânea.
- **Botão de impressão** para exportar PDF.

## Como Usar
1. Abra o arquivo `index.html` no navegador para acessar o índice.
2. Clique na aula desejada para abrir seu conteúdo.
3. Utilize os controles no topo (tema, fonte, imprimir) conforme necessário.

## Personalização
- **CSS**: Ajuste `styles.css` para modificar cores, tipografia ou layout.
- **JS**: Expanda `script.js` para adicionar novas interações ou adaptar o comportamento existente.
