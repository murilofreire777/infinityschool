Definições

Exemplo de parágrafo com inline code e um link para referência. Você pode usar .tag para destacar termos.

  • Algoritmo: sequência finita de etapas para resolver um problema.
  • Variável: espaço nomeado para armazenar valores.
  • Tipo de dado: define a natureza do valor (ex.: inteiro, string).

Boas práticas para exemplos
