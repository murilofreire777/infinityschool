Revisão — Listas e Dicionários

Prática focada em manipulação de listas e dicionários em Python (sem bibliotecas externas).

  • Consolidar domínio de operações comuns (busca, filtro, agregação, transformação).
  • Trabalhar com dados aninhados (listas de dicionários com listas/dicionários internos).
  • Produzir respostas utilizando apenas Python padrão.

Parte 1 — Listas (4 questões)

  1. Filtragem básica — Dada a lista nums = [3, 10, 7, 12, 18, 1, 5], gere uma nova lista apenas com os números pares.
  2. Transformação — Com a lista precos = [10.0, 15.5, 8.9, 21.0], aplique 10% de acréscimo em cada valor e crie uma lista atualizada (arredonde em 2 casas).
  3. Busca/contagem — Em palavras = ["python","dados","python","logica","python","ia"], conte quantas vezes a palavra "python" aparece e liste os índices onde ela ocorre.
  4. Ordenação composta — Dada a lista de tuplas alunos = [("Ana",8.4),("João",7.2),("Lia",9.1),("Rui",7.2)], retorne a lista ordenada por nota decrescente.

Parte 2 — Dicionários (4 questões)

  1. Extração de chaves/valores — Dado produto = {"id":101,"nome":"Teclado","preco":120.0,"estoque":35}, imprima uma frase: “Teclado (id 101) — R$120.00 — Estoque: 35”.
  2. Agrupamento simples — Com vendas = [{"categoria":"A","valor":100},{"categoria":"B","valor":50},{"categoria":"A","valor":30}], calcule o total vendido por categoria, produzindo: {"A":130,"B":50}.
  3. Inversão chave→valor — Dado mapeamento = {"br":"Brasil","us":"Estados Unidos","fr":"França"}, crie o dicionário invertido {"Brasil":"br",...} (não use dict comprehension ainda).
  4. Junção/atualização — Dadas duas parciais: a = {"ana":8.0,"joao":6.5} e b = {"joao":7.2,"lia":9.0}, una as informações em um novo dicionário com a maior nota conhecida por aluno.

Parte 3 — Projeto (Listas + Dicionários): Grade Acadêmica de Tecnologia

Você receberá um dataset (lista de dicionários) representando uma grade de cursos de tecnologia. Use apenas Python puro para responder às questões e completar dados faltantes. Não use Pandas.

Dica: Trabalhe com uma cópia do dataset quando for alterar valores. Use estruturas como set() para unicidade, e funções utilitárias (sum, max, sorted) quando fizer sentido.

Tarefas

  1. Completar dados — Substitua todos os nomes de professores ausentes (None) por "A Definir", sem modificar o restante dos elementos.
  2. Disciplina com maior carga — Encontre a(s) disciplina(s) com maior carga_horaria no conjunto todo e imprima código, nome e carga.
  3. Listas únicas — Extraia:
    • a lista de professores (sem duplicados), ordenada alfabeticamente;
    • a lista de alunos (sem duplicados), ordenada alfabeticamente.
  4. Carga por curso — Para cada curso, calcule a carga horária total (soma das cargas de suas disciplinas).
  5. Mapa disciplina → alunos — Construa um dicionário em que a chave é o codigo da disciplina e o valor é uma lista de alunos sem repetição, ordenada.
  6. Pré-requisitos válidos — Verifique se cada código listado em pre_requisitos existe em alguma disciplina da grade. Liste os códigos inexistentes (se houver).
  7. Trilhas resolvidas — Para cada trilha de cada curso, gere uma lista de objetos com {"codigo","nome","carga_horaria"} referente a cada disciplina da trilha. (Mantenha a ordem original da trilha.)
  8. Alunos por curso — Para cada curso, gere um conjunto (ou lista única ordenada) com todos os seus alunos (sem duplicados).
  9. Relatório geral — Monte um pequeno relatório de texto (strings concatenadas) com:
    • Quantidade total de cursos, disciplinas, professores únicos e alunos únicos;
    • Nome(s) da(s) disciplina(s) de maior carga;
    • Carga total por curso.
Regras: Não use bibliotecas externas (sem Pandas). Evite mutar a estrutura original onde não for necessário: se precisar alterar campos, faça uma cópia profunda.
Dica: Construa estruturas auxiliares pequenas (ex.: professores_unicos = [], alunos_unicos = []) para reutilizar lógica e facilitar os testes.
