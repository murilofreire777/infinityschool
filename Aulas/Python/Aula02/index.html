🐍 Python Aula 02 — Dicionários e Conjuntos

Dicionários e Conjuntos (Sets)

Nesta aula você aprenderá a manipular dicionários e conjuntos (sets), estruturas fundamentais da linguagem Python para armazenar e organizar dados.

  • Compreender o funcionamento de dict (pares chave-valor).
  • Aprender a usar set para armazenar elementos únicos.
  • Aplicar operações comuns: inserção, remoção, interseção e união.

Dicionários (dict)

Dicionários armazenam pares chave : valor. São mutáveis e ideais para representar objetos ou registros.

Exemplo
aluno = {
    "nome": "Ana",
    "idade": 20,
    "notas": [8.5, 7.0, 9.2]
}

print(aluno["nome"])
aluno["curso"] = "Python"
print(aluno)

Principais métodos

  • keys() → retorna as chaves
  • values() → retorna os valores
  • items() → retorna pares (chave, valor)
  • get(chave, valor_padrão) → busca segura
  • pop(chave) → remove um item
Iterando sobre dicionário
for chave, valor in aluno.items():
    print(chave, "→", valor)

Conjuntos (set)

Conjuntos são coleções não ordenadas e sem elementos duplicados. São úteis para operações matemáticas entre grupos de dados.

Exemplo
alunos_a = {"Ana", "Bruno", "Clara"}
alunos_b = {"Bruno", "Diego", "Elisa"}

# União e interseção
print(alunos_a | alunos_b)  # união
print(alunos_a & alunos_b)  # interseção
print(alunos_a - alunos_b)  # diferença

Principais métodos

  • add() → adiciona elemento
  • remove() / discard() → remove
  • union() → une dois conjuntos
  • intersection() → retorna elementos comuns
  • difference() → retorna elementos exclusivos

Exercícios

Dicionários

  1. Cadastro simples — Crie um dicionário com nome, idade e cidade. Exiba os dados formatados.
  2. Notas de alunos — Guarde nomes e médias em um dicionário e mostre quem foi aprovado (≥7).
  3. Conversor de moedas — Armazene cotações (ex: dólar, euro, libra) e converta um valor digitado.
  4. Contagem de letras — Conte quantas vezes cada letra aparece em uma palavra digitada.
  5. Agenda telefônica — Armazene nomes e telefones em um dicionário e permita consultar pelo nome.

Conjuntos (Sets)

  1. Alunos em cursos — Crie dois conjuntos de nomes e mostre quem está em ambos os cursos.
  2. Números únicos — Peça 10 números e mostre apenas os valores distintos.
  3. Vogais na frase — Leia uma frase e mostre as vogais encontradas (sem repetição).
  4. Comparação de conjuntos — Crie dois conjuntos de números e mostre união, interseção e diferença.
  5. Cadastro sem duplicatas — Peça nomes até “fim” e armazene num conjunto, impedindo repetições.
Dica: Dicionários e conjuntos são estruturas essenciais para manipular dados reais — listas telefônicas, registros, grupos, resultados de pesquisa, etc.
