Revisão de Lógica — Listas e Tuplas

Nesta aula revisaremos os principais conceitos de lógica de programação aplicados à linguagem Python, com foco em listas e tuplas.

  • Revisar o uso de estruturas condicionais e de repetição.
  • Compreender a diferença entre listas e tuplas.
  • Manipular coleções com métodos e funções nativas.

Relembrando as estruturas

Tipos de dados

Exemplo
idade = 25          # int
altura = 1.75       # float
nome = "Maria"      # str
ativo = True        # bool
# Nós vimos também
#usuarios = ['adm', 'usr'] #list (listas)
#resultados = (2, 3, 5 , 7) #tuple (tuplas)

Condicionais (if elif else)

Exemplo
idade = int(input("Idade: "))
if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")

Laços (for e while)

Exemplo (while)
i = 0
while i < 5:
    print(f"Contagem: {i}")
    i += 1
Exemplo (for)
for i in range(5):
    print(f"Contagem: {i}")

Tuplas

Tuplas são coleções imutáveis. Elas são criadas com parênteses e não permitem alterações nos elementos.

Exemplo
cores = ("azul", "verde", "vermelho")
print(cores[0])  # azul
print(len(cores))# 3
#Iterando
for c in cores:
    print(c)

Listas

Listas são estruturas mutáveis, ideais para armazenar conjuntos de dados que podem mudar.

Operações básicas
frutas = ["maçã", "banana", "uva"]
frutas.append("pera")
frutas.remove("banana")
print(frutas)
print(frutas[0].upper())

Principais métodos:

  • append() — adiciona no final
  • insert() — insere em posição específica
  • pop() — remove o último ou em posição específica
  • remove() — remove um item (por valor)
  • sort() — ordena a lista
  • len() — conta os itens da lista
Dica: Você pode usar laços para percorrer strings. 
for letra in "Abracadabra":
    print(letra)
  # Além de fazer acesso posicional
  print("Abracadabra"[0]) # A
Dica: Você pode converter de tuplas para listas e vice versa. 
numeros = [1, 2, 3, 4, 5] # list
numeros = tuple(numeros) # O tipo muda para tuple
numeros = list(numeros) # o tipo volta a ser list
Dica: O operador 'in' pode verificar se um elemento consta em uma coleção. 
numeros = ['a', 'b', 'c']
if 'a' in numeros: 
    print("A lista contém o elemento 'a'")

Exercícios

Condicionais

  1. Maioridade revisada — Peça a idade e diga se é maior ou menor de idade.
  2. Nota e aprovação — Peça a nota e diga se está aprovado (≥ 7) ou reprovado.

Laços de repetição

  1. Contagem com for — Mostre os números de 1 a 10.
  2. Soma de pares — Some todos os números pares de 1 a 100 com for.

Tuplas

  1. Meses do ano — Crie uma tupla com os 12 meses e exiba o mês correspondente a um número digitado.

Listas

  1. Cadastro de nomes — Leia 5 nomes e exiba-os em ordem alfabética.
  2. Média e maiores — Leia 5 notas em uma lista, calcule a média e mostre as notas acima da média.
  3. Maior e menor valor — Peça 5 números e mostre o maior e o menor.
  4. Remoção de repetidos — Leia números até digitar 0 e crie uma lista sem repetições.
  5. Junção de listas — Crie duas listas de 3 números e gere uma terceira com a soma elemento a elemento.
Dica: A revisão de lógica é essencial antes de avançar para estruturas de dados mais complexas. Refaça os exercícios com pequenas variações!
